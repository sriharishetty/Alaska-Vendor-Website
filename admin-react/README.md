# React Admin

Run `npm install` once, then use `npm run dev` for development or `npm run build` to create `../admin-react-dist`. The production bundle is a classic script, so `admin-react-dist/index.html` works when opened directly from the file system. The app uses the existing Production Operations localStorage keys, including `productionOperationsVendors`. Its migrated defaults are stored in `src/generated-default-data.js`.
